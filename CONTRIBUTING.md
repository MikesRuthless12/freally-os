# Contributing to Freally OS

Thank you for looking. Freally OS is open source (Apache-2.0), and you're welcome to read it, build it, learn from it and fork it.

## What's welcome

- **Issues:** bugs, crashes, a screen that says something wrong.
- **Hardware reports:** what happened when you booted it on your machine (the make, the model, a photo of the screen).
- **Security reports:** please don't open a public issue. See [`SECURITY.md`](SECURITY.md).

## What isn't merged: pull requests

Pull requests aren't merged, however good they are. Only Mike changes Freally OS. It's one person's operating system, written line by line by its owner, and the seal (official machines run only code signed with his key) is part of what it promises its users.

If you want to change it, fork it under another name and with your own signing key (see [`TRADEMARKS.md`](TRADEMARKS.md)). The licence gives you every right to.
